# Live Slides Timer

Live Slides Timer is a free Chrome extension for adding a live countdown or stopwatch to a Google Slides presentation.

Official website: https://www.slidestimer.com/

Chrome Web Store: https://chromewebstore.google.com/detail/live-slides-timer/dlhbmoonnaipppbcdechfbkooljfopcn

## Presentation timer workflow

1. Install the extension.
2. Open a Google Slides deck and add a text box.
3. Type a tag such as `{{5:00-}}`.
4. Click Present. The tag becomes a live countdown.

Modifiers:

- `{{0:00+}}` starts a stopwatch.
- Add `|@` to play a bell when the countdown ends.
- Add `|]` to advance to the next slide when the countdown ends.

The extension popup can switch tag markers to the older `<< >>` form.
